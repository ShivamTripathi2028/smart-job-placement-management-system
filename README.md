# Smart Job and Placement Management System

A backend-based Job and Placement Management System developed using Java, Spring Boot, Spring Data JPA, and MySQL.

The system provides RESTful APIs to manage students, companies, jobs, job applications, placements, and placement dashboard statistics.

## 🚀 Features

- Student Management
- Company Management
- Job Management
- Job Application Management
- Placement Management
- Input Validation
- Global Exception Handling
- Dashboard Summary
- Application Statistics
- Placement Statistics
- RESTful APIs
- MySQL Database Integration

## 🛠️ Technologies Used

- Java 21
- Spring Boot 4.1.1
- Spring Web
- Spring Data JPA
- Jakarta Bean Validation
- MySQL
- Maven
- Postman
- VS Code
